### Data Models Integration
**Fulfillment Workflow Schema**:
```sql
-- Fulfillment workflow tracking
CREATE TABLE fulfillment_workflows (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
    roaster_id UUID REFERENCES roasters(id),
    workflow_type VARCHAR(50) DEFAULT 'standard',
    current_step VARCHAR(100) NOT NULL,
    steps_completed JSONB DEFAULT '[]',
    estimated_completion TIMESTAMP,
    actual_completion TIMESTAMP,
    workflow_data JSONB DEFAULT '{}',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Shipping integration records
CREATE TABLE shipping_records (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
    shipstation_order_id VARCHAR(255),
    carrier VARCHAR(100),
    service_code VARCHAR(100),
    tracking_number VARCHAR(255),
    shipping_cost DECIMAL(8,2),
    label_url TEXT,
    shipped_at TIMESTAMP,
    delivered_at TIMESTAMP,
    delivery_status VARCHAR(50),
    tracking_events JSONB DEFAULT '[]',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Quality control records
CREATE TABLE quality_checks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
    check_type VARCHAR(100) NOT NULL,
    performed_by UUID REFERENCES users(id),
    status VARCHAR(50) DEFAULT 'pending',
    results JSONB DEFAULT '{}',
    notes TEXT,
    images JSONB DEFAULT '[]',
    performed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Fulfillment Workflow States
**Workflow Steps**:
1. **Order Received** - Order assigned to roaster
2. **Acknowledged** - Roaster confirms order receipt
3. **Inventory Check** - Verify product availability
4. **Preparation** - Order preparation and packaging
5. **Quality Check** - Quality control validation
6. **Shipping Label** - Generate shipping label and documentation
7. **Shipped** - Package handed to carrier
8. **In Transit** - Package in transit to customer
9. **Delivered** - Package delivered to customer
10. **Completed** - Order completion confirmed

### API Integration Points
**Roaster Portal Endpoints**:
- `GET /roasters/{roaster_id}/orders/pending` - Get pending orders for roaster
- `POST /roasters/{roaster_id}/orders/{order_id}/acknowledge` - Acknowledge order receipt
- `PUT /roasters/{roaster_id}/orders/{order_id}/status` - Update fulfillment status
- `POST /roasters/{roaster_id}/orders/{order_id}/ship` - Mark order as shipped
- `GET /roasters/{roaster_id}/fulfillment/dashboard` - Fulfillment performance metrics

**ShipStation Integration Endpoints**:
- `POST /shipping/shipstation/orders` - Create ShipStation order
- `GET /shipping/shipstation/rates` - Get shipping rates
- `POST /shipping/shipstation/labels` - Generate shipping labels
- `GET /shipping/tracking/{tracking_number}` - Get tracking information
