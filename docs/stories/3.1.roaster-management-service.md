### Data Models Integration
**Roaster Entity Operations** [Source: architecture/database-schema.md#roasters]:
```sql
-- Roasters with Stytch integration
CREATE TABLE roasters (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    stytch_org_id VARCHAR(255) UNIQUE NOT NULL, -- Stytch organization ID for roaster
    business_name VARCHAR(255) NOT NULL,
    display_name VARCHAR(255) NOT NULL,
    business_address JSONB NOT NULL,
    coordinates POINT, -- PostGIS for distance calculations
    service_radius INTEGER, -- miles, null for national
    is_national BOOLEAN DEFAULT false,
    stripe_connect_account_id VARCHAR(255),
    approval_settings JSONB DEFAULT '{}',
    capacity_limit INTEGER DEFAULT 50,
    current_partnerships INTEGER DEFAULT 0,
    shipping_settings JSONB DEFAULT '{}',
    feature_flags JSONB DEFAULT '{}', -- Cached from Stytch
    status VARCHAR(50) DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Roaster Data Model** [Source: architecture/data-models.md#roaster]:
- **Purpose**: Coffee providers who fulfill orders and manage product catalogs

- **Relationships**: Has many organizations, has many products, has many shipping configurations

### Geographic Matching Algorithm
**Matching Criteria** [Source: architecture/core-workflows.md#organization-onboarding]:
1. **Distance Validation**: Organization location within roaster service radius
2. **Capacity Check**: Roaster has available partnership slots
3. **Auto-Approval**: Organization meets roaster's approval criteria
4. **Preference Scoring**: Match quality based on roaster preferences
5. **Ranking**: Sort matches by distance, capacity, and preference scores

**PostGIS Queries**:
```sql
-- Find roasters within service area of organization
SELECT r.*, ST_Distance(r.coordinates, o.coordinates) as distance
FROM roasters r, organizations o
WHERE o.id = $1
AND (r.is_national = true OR ST_DWithin(r.coordinates, o.coordinates, r.service_radius * 1609.34))
AND r.current_partnerships < r.capacity_limit
AND r.status = 'active'
ORDER BY distance ASC;
```
