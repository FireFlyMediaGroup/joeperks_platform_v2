BEGIN

**Matching Score Calculation**:

2. **Capacity Score** (30%): Available capacity vs required
3. **Service Score** (20%): Service area coverage quality
4. **Preference Score** (10%): Roaster preferences and criteria

### Performance Optimization
**Spatial Query Optimization**:
```sql
-- Optimized roaster matching query
SELECT r.*, 
       ST_Distance(r.coordinates, $1) as distance_meters,
       (ST_Distance(r.coordinates, $1) * 0.000621371) as distance_miles
FROM roasters r
WHERE r.status = 'active'
  AND r.current_partnerships < r.capacity_limit
  AND (r.is_national = true OR ST_DWithin(r.coordinates, $1, r.service_radius * 1609.34))
ORDER BY distance_meters ASC
LIMIT 10;
```

**Caching Strategy**:
- **Geocoding Results**: Cache address-to-coordinate mappings
- **Distance Calculations**: Cache frequently calculated distances
- **Matching Results**: Cache roaster matches for common locations
- **Service Areas**: Cache service area polygon calculations

### Shipping Cost Calculation
**Distance-Based Shipping Zones**:
```typescript
interface ShippingZone {
  name: string;
  minDistance: number;
  maxDistance: number;
  baseCost: number;
  perMileCost: number;
  estimatedDays: number;
}

const calculateShippingCost = (distance: number, zones: ShippingZone[]) => {
  const zone = zones.find(z => distance >= z.minDistance && distance <= z.maxDistance);
  return zone ? zone.baseCost + (distance * zone.perMileCost) : null;
};
```
