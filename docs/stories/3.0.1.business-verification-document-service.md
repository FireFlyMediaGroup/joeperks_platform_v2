## User Story

As a **roaster owner setting up my business**,
I want **to upload and manage required business verification documents**,
So that **I can complete the verification process and get approved to start accepting partnerships**.

## Acceptance Criteria

**Functional Requirements:**
1. Roasters can upload business license, tax ID, and insurance documents
2. Document status tracking shows verification progress (pending, approved, rejected)
3. Document replacement and resubmission functionality is available when required

**Integration Requirements:**
4. Existing roaster registration continues to work unchanged
5. New document management follows existing service pattern from roaster.service.ts
6. Integration with file upload system maintains current security standards

**Quality Requirements:**
7. Document upload is covered by unit and integration tests
8. File validation prevents malicious uploads and ensures proper document types
9. No regression in existing roaster onboarding functionality verified

## Business Verification Documents

**Required Document Types:**
1. **Business License**: Valid state/local business operating license
2. **Tax Identification**: Federal EIN or state tax ID documentation
3. **Insurance Documentation**: Product liability and general business insurance
4. **Address Verification**: Utility bill or lease agreement for business address

**Document Statuses:**
- PENDING: Document uploaded, awaiting review
- APPROVED: Document verified and accepted
- REJECTED: Document rejected, resubmission required
- EXPIRED: Previously approved document needs renewal

### Data Model Extensions
**Business Document Entity**:
```sql
CREATE TABLE business_documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    roaster_id UUID REFERENCES roasters(id) ON DELETE CASCADE,
    document_type VARCHAR(50) NOT NULL, -- business_license, tax_id, insurance, address_verification
    document_name VARCHAR(255) NOT NULL,
    file_path VARCHAR(500) NOT NULL,
    file_size INTEGER NOT NULL,
    mime_type VARCHAR(100) NOT NULL,
    status VARCHAR(50) DEFAULT 'pending', -- pending, approved, rejected, expired
    rejection_reason TEXT,
    expires_at TIMESTAMP,
    reviewed_at TIMESTAMP,
    reviewed_by UUID,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Document Type Requirements
**Document Validation Rules**:
- Business License: PDF, JPG, PNG up to 10MB
- Tax ID Documents: PDF, JPG, PNG up to 5MB
- Insurance Certificates: PDF up to 10MB
- Address Verification: PDF, JPG, PNG up to 5MB

**File Security**:
- Virus scanning for uploaded files
- Document isolation by roaster ID
- Secure file naming to prevent conflicts
- Access control based on roaster ownership

### Integration with Roaster Approval
**Approval Workflow Integration**:
- Roaster status remains "pending" until all required documents approved
- Document rejection triggers notification and status explanation
- Completed document verification enables roaster activation
- Document expiration warnings sent before renewal needed

### Administrative Features
**Admin Document Review**:
- Document preview interface for platform admins
- Approval/rejection workflow with reason tracking
- Batch document processing for efficiency
- Document history and audit trail

## Risk Assessment

**Primary Risk:** Document uploads containing malicious files or exceeding storage limits
**Mitigation:** Comprehensive file validation, virus scanning, and storage quotas with monitoring
**Rollback:** Feature flag to disable document uploads if security issues arise
